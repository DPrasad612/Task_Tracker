Task Tracker

A full-stack productivity application built to help users manage tasks, track progress, and stay accountable to their goals.

The project started from a simple problem: most task management apps either lacked the flexibility I wanted or required adapting to their workflow. Instead of searching for the perfect solution, I decided to build one that matched the way I wanted to organize my work, learning goals, coding practice, and personal projects.

Live Demo

https://task-tracker-5id4.onrender.com

Features

Smart Task Management

- Create and manage tasks with ease
- Organize tasks using categories
- Assign priority levels
- Track task completion progress
- Create and manage subtasks

Flexible Scheduling

- Start Date and End Date support
- Weekday-based recurring tasks
- Time-specific tasks for events such as:
  - Coding contests
  - Online assessments
  - Interviews
  - Meetings
  - Exam schedules

Progress Tracking

- Visual progress indicators
- Completion percentages
- Streak tracking
- Weekly planning and monitoring

User Experience

- Responsive web application
- Android APK version
- Authentication and secure user data
- Clean and intuitive interface

Installation

Clone the Repository

git clone https://github.com/DPrasad612/Task_Tracker.git
cd Task_Tracker

Install Dependencies

npm install

Configure Environment Variables

Create a ".env" file and add the required environment variables.

DATABASE_URL=your_database_url

Run the Development Server

npm run dev
